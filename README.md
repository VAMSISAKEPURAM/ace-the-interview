## 🌟 What is Ace The Interview?

**Ace The Interview** is a voice-first AI interview coaching assistant that helps Data Science and Generative AI candidates practice articulating their answers out loud — the way they would in a real interview.

Unlike typing-based tools, this app lets you:
- 🎤 **Speak your question** directly into the microphone
- 🤖 **Receive a spoken candidate-perspective answer** generated by Groq LLaMA 3.3
- 🔊 **Listen back** at a comfortable pace and refine your delivery

## ✨ Key Features

| Feature | Description |

| 🎤 **Hands-Free Voice Input** | Browser microphone capture using Web Speech API |
| ⚡ **Groq LLaMA 3.3 (70B) LLM** | Ultra-fast inference for near zero-latency responses |

| 📢 **Domain Restriction Guardrail** | Politely declines off-topic questions outside Data Science & AI |
| 🔊 **Crystal-Clear Audio Playback** | Calibrated speech synthesis at comfortable listening pace |
| 📝 **Text Input Fallback** | Type your question if microphone is unavailable |

| 🔄 **Reset Conversation** | Clear history and start fresh with one click |
| 🎨 **Glassmorphism Dark UI** | Premium modern design with smooth animations |

## 🎯 Covered Topics (Strict Domain Focus)

The assistant **exclusively** answers questions in the following domains:

- 📊 **Data Science** — EDA, Feature Engineering, Model Evaluation, Statistics
- 🤖 **Machine Learning** — Supervised, Unsupervised, Ensemble methods, Regularization
- 🧠 **Deep Learning** — CNNs, RNNs, LSTMs, Transformers, Attention Mechanisms
- 💬 **Natural Language Processing (NLP)** — Tokenization, Embeddings, BERT, GPT
- 🖼️ **Computer Vision** — Object Detection, Segmentation, Image Classification
- 🔁 **MLOps** — Model Deployment, Monitoring, CI/CD Pipelines, Docker, Kubernetes
- 🚀 **Generative AI** — LLMs, Prompt Engineering, RAG, Fine-Tuning, Vector Databases
- 📈 **Statistics & Probability** — Hypothesis Testing, Distributions, Bayesian Inference

> ⚠️ If a question is outside these domains, the assistant responds:
> *"I am specifically designed for Data Science and Generative AI interview preparation. Please ask a question related to Data Science, Machine Learning, or AI concepts."*

## 🚀 How to Run Locally

### 1. Clone the Repository
```bash
git clone https://github.com/VAMSISAKEPURAM/ace-the-interview.git
cd ace-the-interview
```

### 2. Set Up Environment Variables
```bash
cp .env.example .env
# Edit .env and add your Groq API Key
```

### 3. Install Python Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the FastAPI Backend
```bash
uvicorn server:app --reload --port 8000
```

### 5. Open in Browser
Visit `http://localhost:8000` and start speaking!

## 📁 Project Structure

```
ace-the-interview/
├── index.html              # Main app entry point (Static Space)
├── app.js                  # Core voice chatbot logic (Web Speech API + Groq)
├── styles.css              # Glassmorphism UI design system
├── app.py                  # Gradio UI (alternative deployment)
├── server.py               # FastAPI REST backend
├── config.py               # Centralized configuration
├── conversation/
│   ├── prompt.py           # Groq LLM system prompts
│   ├── history.py          # Conversation history manager
│   └── memory.py           # Context window memory pruner
├── models/
│   ├── groq_model.py       # Groq LLaMA 3.3 API client wrapper
│   ├── whisper_model.py    # HF Whisper STT pipeline
│   └── tts_model.py        # HF MMS-TTS synthesis pipeline
├── services/
│   ├── llm_service.py      # LLM service layer
│   ├── speech_to_text.py   # STT service layer
│   └── text_to_speech.py   # TTS service layer
├── static/                 # Frontend assets (CSS, JS, HTML)
├── tests/                  # Automated unit tests
├── requirements.txt        # Python dependencies
├── .env.example            # Environment variable template
└── README.md               # This file
```

## 🔐 Security

- ✅ API keys are **never hardcoded** in source code
- ✅ `.env` file is excluded from Git via `.gitignore`
- ✅ Browser-side keys are stored in `localStorage` and prompted on first use
- ✅ `.env.example` is the only public template (contains no real credentials)
